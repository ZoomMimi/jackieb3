## How to work this list

1. Start the preview server with drafts visible: `npm run dev:drafts`, then open each post's link below.

2. Edit the post's `.mdx` file in `src/content/blog/great-loop/` to fix facts, add memories, and adjust voice.
3. When you're happy with a post, change `draft: true` to `draft: false` in its frontmatter and tick its box here. Only you flip that flag.
4. Check progress any time with `npm run verify-phase6` — `DRAFT_POSTS` counts only these posts and reads 0 when you're done.

- **Bible verse:** the closing verse was never verified. Confirm the quoted words actually match the cited reference, and that it's the verse you'd choose.
